- s37 (relation URLs, 2026-09-12, read-only, scratch #15553): **the service rewrites a relation's URL with the project GUID.** The app sends `https://dev.azure.com/puremedia/DevOps%20Mobile%20App/_apis/wit/attachments/{guid}` (and the work item URL the search read gave it); every relation comes back as `https://dev.azure.com/puremedia/98720989-0195-48cb-ae2e-0e58ec1bb9a9/_apis/wit/{attachments|workItems}/...`, with the `?fileName=` query dropped. - **Moving a task on the taskboard (w33/w34/w35, scratch writes).** `PATCH {project}/{team}/_apis/work/taskboardworkitems/{iterationId}/{workItemId}?api-version=7.1-preview.1` takes `{"newColumn": "<column name>"}` — the parameter is **`newColumn`**, a **name** not an id (`newColumnId` alone is a 400 "Value cannot be null.
