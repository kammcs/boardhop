## Ranked defects

1. **PR reviewers render as initials instead of photos (finding b is not fixed for
   reviewers).** `ip_104_pr` / `iphone_worst_1`. Root cause is exact:
   `lib/data/models/pull_request.dart:48-49` takes `imageUrl` through
   `IdentityRef.fromJson(json).imageUrl` (which does prefer `_links.avatar`) but takes
   `descriptor: json['descriptor'] as String?` **raw** — and spike s23 established that
   reviewers carry no `descriptor` field. So `PrReviewer.identity.descriptor` is always null,
   `IdentityRef.avatarSource` falls through to the MemberAvatars / identityImage URL, which
   401s to the Entra token, and the row degrades to initials. Fix: use
   `IdentityRef.fromJson(json).descriptor` (which already calls `descriptorFromAvatar`).
   Owner: **`lib/data/models/pull_request.dart`**. Check pipeline approvers for the same
   pattern.

2. **The edit form shows the links list twice.** `ip_72_links` / `iphone_worst_2`. The Details
   page's "Related Work" panel and the phase-5 **Links** section render the same rows with the
   same x buttons and the same "Add link" button, one directly above the other, so a phone
   form for an item with a parent carries two identical editable panels. Either suppress
   Related Work when the Links section is appended, or make Related Work read-only.
   Owner: **`lib/features/work_items/form/work_item_form_body.dart`** plus
   **`lib/features/work_items/form/controls/links_section.dart`**.

3. **Attachments from the photo library are named `image_picker_<GUID>`.** `ip_87_picked` /
   `iphone_worst_3`. The plugin's temp filename is uploaded verbatim, so the attachment list
   (and Azure DevOps web) shows a 40-character GUID. Give it a readable name
   (`photo-20260912-1215.jpg`, or the asset's own name).
   Owner: **`lib/features/work_items/form/controls/attachments_section.dart`**.

4. **Deployment and Development do not show "Managed in Azure DevOps" on the detail page.**
   They do in the form (`ip_12_form_scroll`) but are absent from `ip_31_detail` and
   `ip_50_child`. If the detail page is meant to mirror the web's Details page, the two panel
   groups should render their placeholder there too.
   Owner: **`lib/features/work_items/work_item_detail_page.dart`** (`detailGroupsFor`).

5. **The full-screen attachment viewer is not full screen.** `ip_88_viewer`: the bottom tab bar
   stays visible, the background is the light page colour and the image is letterboxed in the
   middle. A photo viewer should go edge to edge on a dark ground.
   Owner: **`lib/features/work_items/form/controls/attachments_section.dart`**.

6. **The iPhone in portrait keeps the full-width Material `NavigationBar`, not the glass
   pill.** `ip_03_home`. `ProjectShell` returns the Material bar for every **compact** window
   before it ever reaches `GlassShellLayout`
   (`lib/features/projects/project_shell.dart:147`), so the "rail along the bottom at 80% of
   the width" that NEXT-STEPS describes only ever applies to the iPad. In landscape the phone
   does get the glass rail (`ip_143_land_right`), so the same device switches chrome family on
   rotation. Kelly's call whether that is intended.
   Owner: **`lib/features/projects/project_shell.dart`**.

7. **The html editor prints on every keystroke in debug.** About 30 `{style: p, fontName: …}`
   maps plus 3 x `JavaScript execution returned a result of an unsupported type` in
   `run_iphone3.log`. Harmless, but it buries real log lines during a walkthrough.
   Owner: **`lib/features/work_items/widgets/html_field_editor.dart`**.

8. **In phone landscape the anchored type-chooser menu runs off the bottom of the screen.**
   `ip_145_land_form`: the last row ("Boardhop spike task" under the second Task) is clipped by
   the screen edge. Cap the menu height to the safe area.
   Owner: **`lib/features/work_items/form/type_chooser.dart`**.

9. **"Add child" on a Task offers Task and Bug.** `ip_52_child_of_task`. A Task is the lowest
   backlog level; the child chooser falls back to the same set as a User Story's. Legal in the
   link rules, but probably not intended.
   Owner: **`lib/data/models/work_item_form.dart`** (`BacklogTypes.childTypeNames`).

10. *(cosmetic)* **At xxxL the PR tab label "Comments (3)" is cut off at the screen edge**
    (`ip_134_xxxl_pr`). The strip scrolls, so it is reachable.

11. *(cosmetic)* **Kelly appears twice in the people picker** — once as the pinned
    "Kelly Kamm (Me)" and again in the team-member list below (`ip_16_people`,
    `ip_140_xxxl_picker`). Phase 2 claims "the same person no longer appears twice"; the
    de-duplication does not cover the pinned "Me" row.
    Owner: **`lib/features/work_items/form/controls/`** (people picker).
